# Plan: Motor Mixing Matrix + MAVLink Waypoint Navigation

## Overview

Replace the oscillating fin system with a configurable motor mixing matrix for 4 static motors, and add MAVLink waypoint navigation for autonomous A→B flight.

**New control axes:** Yaw (rotation), Pitch (rotation), Roll (rotation), X (linear forward/backward)

---

## Part 1: Motor Mixing Matrix

### 1.1 New `MotorMix` class (replaces `Fins`)

**File: `MotorMix.h` / `MotorMix.cpp`** (new files, replaces `Fins.h` / `Fins.cpp`)

```cpp
class MotorMix {
public:
    // 4 control axes (outputs from PID controllers)
    float yaw_out;    // [-1, +1] rotational around Z
    float pitch_out;  // [-1, +1] rotational around Y
    float roll_out;   // [-1, +1] rotational around X
    float x_out;      // [-1, +1] linear along X

    // Mixing matrix: 4 motors × 4 axes
    // motor_output[m] = Σ(axis_weight[m][a] * axis_out[a])
    AP_Float motor_yaw[4];    // M1_YAW..M4_YAW
    AP_Float motor_pitch[4];  // M1_PITCH..M4_PITCH
    AP_Float motor_roll[4];   // M1_ROLL..M4_ROLL
    AP_Float motor_x[4];      // M1_X..M4_X

    void output();       // Apply mixing matrix, write to SRV_Channels
    void output_min();   // Zero all outputs
    void setup_motors(); // Initialize SRV_Channel angles

    // Arming state
    void armed(bool arm);
    bool armed() const;

    // Throttle indicator for MAVLink
    float get_throttle();
};
```

**Mixing logic in `MotorMix::output()`:**
```cpp
void MotorMix::output() {
    if (!_armed) {
        yaw_out = pitch_out = roll_out = x_out = 0;
    }

    // Constrain inputs
    yaw_out   = constrain_float(yaw_out, -1, 1);
    pitch_out = constrain_float(pitch_out, -1, 1);
    roll_out  = constrain_float(roll_out, -1, 1);
    x_out     = constrain_float(x_out, -1, 1);

    // Log inputs
    Write_MOTORI(yaw_out, pitch_out, roll_out, x_out);

    // Apply mixing matrix
    for (int i = 0; i < 4; i++) {
        float output = motor_yaw[i] * yaw_out
                     + motor_pitch[i] * pitch_out
                     + motor_roll[i] * roll_out
                     + motor_x[i] * x_out;
        output = constrain_float(output, -1, 1);
        SRV_Channels::set_output_scaled(SRV_Channels::get_motor_function(i), output * MOTOR_SCALE_MAX);
    }

    Write_MOTORO(...);
}
```

**Parameters (in `MotorMix::var_info`):**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `M1_YAW` | 0 | Motor 1 yaw contribution |
| `M1_PITCH` | 0 | Motor 1 pitch contribution |
| `M1_ROLL` | 0 | Motor 1 roll contribution |
| `M1_X` | 0 | Motor 1 X contribution |
| `M2_YAW` | 0 | Motor 2 yaw contribution |
| ... | ... | ... |
| `M4_X` | 0 | Motor 4 X contribution |

## Part 2: Loiter Controller Adaptation

### 2.1 Update `Loiter.h` / `Loiter.cpp`

Rename axes throughout:

| Old | New |
|-----|-----|
| `front_out` | `x_out` |
| `right_out` | `roll_out` |
| `down_out` | `pitch_out` |
| `yaw_out` | `yaw_out` |

**Key changes in `Loiter::run()`:**
- Position PID: target_pos → target_vel for X, pitch, roll, yaw
- Velocity PID: target_vel → actuator for X, pitch, roll, yaw
- Output assignment: write to `motors->x_out`, `motors->roll_out`, `motors->pitch_out`, `motors->yaw_out`

**Scaler changes:**
- Replace `scaler_xz` with appropriate scaler for the new axis pairs
- Replace `scaler_yyaw` similarly

**Coordinate frame consideration:**
- X is linear forward/backward (body frame)
- Pitch/Roll are rotational (body frame)
- Yaw is rotational (world frame)
- Position control for X uses NED X coordinate
- Pitch/Roll position control uses attitude (not position in NED)
- Need to decide: do pitch/roll control position or attitude?

**Recommended approach:** Since this is a blimp with buoyancy:
- X: position control (NED X coordinate)
- Yaw: position control (heading angle)
- Pitch: attitude control (small angles, body frame)
- Roll: attitude control (small angles, body frame)

## Part 3: MAVLink Waypoint Navigation

### 3.1 New `ModeAuto` flight mode

**File: `mode_auto.cpp` / `mode_auto.h`** (new files)

```cpp
class ModeAuto : public Mode {
public:
    bool init(bool ignore_checks) override;
    void run() override;
    bool requires_GPS() const override { return true; }
    bool has_manual_throttle() const override { return false; }
    bool allows_arming(bool from_gcs) const override { return true; }
    bool is_autopilot() const override { return true; }

    // Waypoint management
    void set_target(const Location& loc);
    bool has_target() const;
    Location get_target() const;

private:
    Location _target_loc;
    bool _has_target = false;
    float _target_yaw = 0;
};
```

**`ModeAuto::run()`:**
```cpp
void ModeAuto::run() {
    if (!_has_target) {
        // No waypoint - hover in place
        motors->x_out = 0;
        motors->roll_out = 0;
        motors->pitch_out = 0;
        motors->yaw_out = 0;
        return;
    }

    // Convert target Location to NED position
    Vector3f target_ned = location_to_ned(_target_loc);
    float target_yaw = _target_yaw;

    // Use loiter controller for position hold
    blimp.loiter->run(target_ned, target_yaw, Vector4b{false,false,false,false});

    // Check if reached target
    float dist = (target_ned - blimp.pos_ned).length();
    if (dist < WP_RADIUS) {
        // Waypoint reached
        advance_to_next_waypoint();
    }
}
```

```cpp
MAV_RESULT GCS_MAVLINK_Blimp::handle_mission_item_int(
    const mavlink_command_int_t &packet)
{
    // Convert MAVLink frame to Location
    Location loc;
    loc.lat = packet.x;  // latitude * 1e7
    loc.lng = packet.y;  // longitude * 1e7
    loc.alt = packet.z * 100;  // meters to cm
    loc.frame = MAV_FRAME_GLOBAL_RELATIVE_ALT;

    // Store waypoint
    uint8_t index = packet.param1;
    float yaw = packet.param4;
    blimp.waypoint_manager.set_waypoint(index, loc, yaw);

    return MAV_RESULT_ACCEPTED;
}
```

## Part 4: Flight Mode Adaptation

### 4.1 Update `mode_manual.cpp`

```cpp
void ModeManual::run() {
    Vector3f pilot;
    float pilot_yaw;
    get_pilot_input(pilot, pilot_yaw);

    // Map RC channels to new axes:
    // Roll stick → roll_out
    // Pitch stick → pitch_out
    // Throttle stick → x_out (forward/backward)
    // Yaw stick → yaw_out
    motors->roll_out = pilot.y;
    motors->pitch_out = pilot.z;  // was down_out
    motors->x_out = pilot.x;     // was front_out
    motors->yaw_out = pilot_yaw;
}
```

### 4.2 Update `mode_velocity.cpp`

```cpp
void ModeVelocity::run() {
    Vector3f target_vel;
    float target_vel_yaw;
    get_pilot_input(target_vel, target_vel_yaw);

    // Scale inputs
    target_vel.x *= g.max_vel_x;     // forward/backward velocity
    target_vel.y *= g.max_vel_roll;  // roll rate
    target_vel.z *= g.max_vel_pitch; // pitch rate
    target_vel_yaw *= g.max_vel_yaw;

    // Body-frame rotation for X and yaw
    if (g.simple_mode == 0) {
        blimp.rotate_BF_to_NE(target_vel.xy());
    }

    blimp.loiter->run_vel(target_vel, target_vel_yaw, Vector4b{false,false,false,false});
}
```

## Risk Assessment

1. **PID tuning**: New axes (pitch/roll) may need significant tuning. Start with conservative gains.
2. **Mixing matrix**: Wrong values can cause unstable flight. Test in SITL first.
3. **Waypoint conversion**: GPS → NED conversion needs careful testing.
4. **Backward compatibility**: Old parameters will be lost. Need format version bump.
