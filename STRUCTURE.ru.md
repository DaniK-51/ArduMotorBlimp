## Введение

### Назначение документа

Этот документ описывает архитектуру, структуру и компоненты репозитория **ArduMotorBlimp** — реализации дирижабля для платформы ArduPilot.

### Текущее состояние

Это ветка **manual-only** — минимальная сборка, содержащая только режимы Manual и BRAKE для первого тестового полёта. Все автономные режимы (Velocity, Loiter, RTL, AUTO) удалены для уменьшения размера прошивки.

---

## Обзор проекта

### Что такое ArduMotorBlimp?

**ArduMotorBlimp** — это моторизованный дирижабль на базе ArduPilot. Использует 4 статичных мотора с настраиваемой матрицей смешивания вместо осциллирующих fin'ов оригинального Blimp.

### Ключевые характеристики

| Параметр | Значение |
|----------|----------|
| **Тип аппарата** | Моторизованный дирижабль |
| **Язык** | C++ |
| **Лицензия** | GPL-3.0 |
| **База** | ArduPilot |
| **Статус** | Manual-only сборка для первого полёта |

## Основные компоненты

### MotorMix — Матрица смешивания моторов

**Файлы:** `MotorMix.h`, `MotorMix.cpp`

Заменяет осциллирующие fin'ы простой матрицей смешивания 4×4.

**4 оси управления:**
| Ось | Поле | Диапазон | Описание |
|-----|------|----------|----------|
| Yaw | `yaw_out` | [-1, +1] | Вращение вокруг Z |
| Pitch | `pitch_out` | [-1, +1] | Вращение вокруг Y |
| Roll | `roll_out` | [-1, +1] | Вращение вокруг X |
| X | `x_out` | [-1, +1] | Линейное движение вперёд/назад |

**Логика смешивания:**
```cpp
for each motor m (0..3):
    motor_out[m] = motor_yaw[m]   * yaw_out
                 + motor_pitch[m] * pitch_out
                 + motor_roll[m]  * roll_out
                 + motor_x[m]     * x_out
    constrain(motor_out[m], -1, 1)
    SRV_Channels::set_output_scaled(k_motor(m+1), motor_out[m] * 1000)
```

**Параметры:** `M1_YAW`..`M4_X` (16 параметров, диапазон -1..1)

### Mode Manual

**Файл:** `mode_manual.cpp`

Прямой пропуск RC — без PID, без стабилизации.

```
CH1 (Roll)     → motors->roll_out
CH2 (Pitch)    → motors->x_out     (вперёд/назад)
CH3 (Throttle) → motors->pitch_out (высота)
CH4 (Yaw)      → motors->yaw_out
```

### Mode BRAKE

**Файл:** `mode_brake.cpp`

Аварийная остановка — обнуляет все выходы моторов. Используется как цель failsafe.

## Система управления

### Поток данных

```
Приёмник RC
    │ PWM [1000..2000]
    ▼
radio.cpp: read_radio()
    │ channel->get_control_in() / 1000 → [-1, +1]
    ▼
mode.cpp: get_pilot_input()
    │
    ▼
mode_manual.cpp: run()
    │ motors->*_out = pilot.*
    ▼
motors.cpp: motors_output()
    │
    ▼
MotorMix.cpp: output()
    │ [yaw, pitch, roll, x] × matrix → [M1..M4]
    │ → PWM 1000-2000 (бидирекциональный)
    ▼
Моторы
```

Для режима Manual не требуются AHRS, EKF, GPS и другие датчики.

## Режимы полёта

### Manual (Режим 1)

**Назначение:** Прямое управление пилотом  
**GPS:** Не требуется  
**Стабилизация:** Нет  
**Датчики:** Не требуются — только ввод RC и матрица смешивания  

Положения стиков напрямую подаются на вход матрицы смешивания.

### BRAKE (Режим 0)

**Назначение:** Аварийная остановка  
**GPS:** Не требуется  
**Стабилизация:** Нет  

Все выходы моторов обнуляются. Используется как цель failsafe при:
- Потере сигнала RC
- Ошибке EKF
- Потере связи с GCS

## Арминг

Арминг по кнопке через AUX канал:

1. Установите AUX канал (5-8) на `AUX_FUNC=31` (ARMDISARM) в Mission Planner
2. Переключатель HIGH → арминг
3. Переключатель LOW → дизарминг

Без рудерного арминга — только по переключателю.

---

## Вывод моторов

Бидирекциональный PWM для каждого мотора:

| PWM | Состояние |
|-----|-----------|
| 1000 | Полный реверс |
| 1500 | Стоп |
| 2000 | Полный вперёд |

## Безопасность

### Цепочка failsafe

```
Потеря RC сигнала (> 500ms)
    → set_failsafe_radio(true)
        → failsafe_radio_on_event()
            → set_mode_brake_failsafe()

Обнаружена ошибка EKF
    → failsafe_ekf_event()
        → set_mode_brake_failsafe()
```

### Арминг

- Управление моторами через руль направления
- Газ должен быть на нуле для дизарминга
- Автоматический дизармин через настраиваемую задержку

## Параметры

### Моторы (MOTOR_*)

| Параметр | По умолчанию | Диапазон | Описание |
|----------|-------------|----------|----------|
| `M1_YAW` | 0 | -1..1 | Вклад мотора 1 в yaw |
| `M1_PITCH` | 0 | -1..1 | Вклад мотора 1 в pitch |
| `M1_ROLL` | 0 | -1..1 | Вклад мотора 1 в roll |
| `M1_X` | 0 | -1..1 | Вклад мотора 1 в X |
| ... | ... | ... | ... |
| `M4_X` | 0 | -1..1 | Вклад мотора 4 в X |

### Система

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `FLTMODE1` | MANUAL | Режим полёта на CH5 низкий |
| `FLTMODE2` | MANUAL | Режим полёта на CH5 средний-низкий |
| `FLTMODE3` | MANUAL | Режим полёта на CH5 средний |
| `FLTMODE4` | MANUAL | Режим полёта на CH5 средний-высокий |
| `FLTMODE5` | MANUAL | Режим полёта на CH5 высокий |
| `SYSID_THISMAV` | 1 | MAVLink system ID |
| `ARMING_DELAY` | 2с | Задержка после арминга |

### Failsafe

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `FS_THR_ENABLE` | 3 | Failsafe газа: 0=Выкл, 3=Всегда BRAKE |
| `FS_THR_VALUE` | 975 | Порог газа failsafe (PWM) |
| `FS_EKF_ACTION` | 1 | Failsafe EKF: 1=Переключить в BRAKE |

## Интеграция с ArduPilot

### Необходимые библиотеки

Этот код транспортного средства зависит от библиотек ArduPilot (не включены в этот репозиторий):

- `AP_HAL` — абстракция оборудования
- `AP_AHRS` — система ориентации
- `AP_Param` — хранение параметров
- `AP_Scheduler` — планировщик задач
- `AP_Logger` — логирование данных
- `SRV_Channel` — вывод серво
- `RC_Channel` — ввод RC
- `GCS_MAVLink` — протокол MAVLink
- `AP_BattMonitor` — мониторинг батареи
- `AP_Arming` — проверки арминга
- `AP_InertialNav` — инерциальная навигация

### Сборка

```bash
# Разместите этот репозиторий как ArduPilot/Blimp/
cd ardupilot
./waf configure --board sitl
./waf blimp
```
