## 1. Обзор архитектуры

Архитектура ArduPilot построена на следующих принципах:

- **HAL (Hardware Abstraction Layer)** — абстракция над аппаратурой, позволяет запускать один и тот же код на разных платформах (ChibiOS, Linux, ESP32, SITL).
- **Бэкенд-паттерн** — многие библиотеки (GPS, Compass, Baro и др.) используют абстрактный интерфейс с конкретными реализациями для каждого типа датчика.
- **Параметры (AP_Param)** — большинство настроек хранятся в EEPROM через систему параметров с макросами `AP_GROUPINFO`.
- **Синглтоны** — основные менеджеры (`AP_GPS`, `AP_AHRS`, `AP_Arming` и др.) доступны через `get_singleton()`.
- **MAVLink** — протокол связи с наземной станцией (`GCS_MAVLink`).

### Префиксы библиотек

| Префикс | Описание |
|---------|----------|
| `AC_` | ArduCopter — библиотеки управления полётом мультиротёров |
| `AP_` | ArduPilot — общие библиотеки, доступные всем транспортным средствам |
| `APM_` | APM Control — классические PID-контроллеры для самолётов |
| `AR_` | ArduRover — библиотеки для наземных транспортных средств |

## 2. Библиотеки управления полётом (AC_)

### AC_AttitudeControl
**Назначение:** Управление угловой ориентацией (тантаж/крен/рыскание) мультиротёра.

Ключевые компоненты:
- `AC_AttitudeControl` — базовый контроллер attitudes
- `AC_PosControl` — контроллер позиции (используется совместно)

Типичное использование:
```cpp
#include <AC_AttitudeControl/AC_AttitudeControl.h>
// Контроллер рассчитывает требуемые моменты на основе целевых углов
attitude_control.input_euler_angle_roll_pitch_euler_rate_yaw(target_roll, target_pitch, target_yaw_rate);
```

Параметры: `ATC_RATE_R_MAX`, `ATC_RATE_P_MAX`, `ATC_RATE_Y_MAX`, `ATC_ACCEL_R_MAX` и др.

---

### AC_AutoTune
**Назначение:** Автоматическая настройка PID-регуляторов для мультиротёра.

Особенности:
- Определяет оптимальные значения P, I, D для roll, pitch и yaw
- Работает в реальном времени во время полёта
- Поддерживает 다양한 типы мультиротёров (quad, hexa, octa, Y6)

Использование: Активируется через.mode `AUTOTUNE` или MAVLink-команду.

---

### AC_Autorotation
**Назначение:** Управление авторотацией для вертолётов (heli).

Особенности:
- Поддерживает автоматическое снижение при отказе двигателя
- Контроль высоты и скорости снижения
- Интеграция с `AP_MotorsHeli_RSC`

---

### AC_Avoidance
**Назначение:** Уклонение от препятствий.

Особенности:
- `AC_Avoid` — основной класс, ограничивающий скорость/высоту для предотвращения столкновений
- Интеграция с `AP_Proximity` и `AP_Fence`
- Поддержка геозонных ограждений и датчиков ближнего действия

---

### AC_CustomControl
**Назначение:** Позволяет реализовать пользовательский контроллер внутри ArduPilot.

Возможности:
- Переключение между основным и пользовательским контроллером через RC-переключатель (опция 109)
- Битовая маска для выбора осей
- Бесшовный переход (bumpless transfer) между контроллерами

Использование: Пользователь пишет свой контроллер как наследник `AC_CustomControl_Backend`.

---

### AC_Fence
**Назначение:** Геозонные ограничения (заборы/ограждения).

Типы заборов:
| Тип | Описание |
|-----|----------|
| `ALT_MAX` | Верхний лимит высоты |
| `ALT_MIN` | Нижний лимит высоты |
| `CIRCLE` | Круговая горизонтальная зона |
| `POLYGON` | Многоугольная горизонтальная зона |

Действия при нарушении: RTL (возврат домой) или Land (посадка).

Параметры: `FENCE_TYPE`, `FENCE_ALTMAX`, `FENCE_RADIUS`, `FENCE_ACTION`.

---

### AC_InputManager
**Назначение:** Управление ручными входами пилота.

Особенности:
- Фильтрация входных сигналов
- Ограничение скорости изменения команд
- Используется для стабилизации ручного управления

---

### AC_PID
**Назначение:** Универсальный PID-регулятор с хранением параметров в EEPROM.

Ключевые особенности:
- Фильтры на входе (D-фильтр, notch-фильтр)
- Ограничение интегральной составляющей (imax)
- SlewLimiter для предотвращения резких скачков
- Сброс интегральной составляющей

```cpp
#include <AC_PID/AC_PID.h>
AC_PID pid(1.0, 0.1, 0.05, 100); // P, I, D, imax
pid.update(error, dt);
```

Параметры: `{NAME}_P`, `{NAME}_I`, `{NAME}_D`, `{NAME}_IMAX`, `{NAME}_FILT` и др.

---

### AC_PrecLand
**Назначение:** Точная посадка с использованием внешних маркеров.

Бэкенды:
- `Companion` — через companion-компьютер
- `IRLock` — инфракрасный датчик
- `SITL_Gazebo` — симуляция

---

### AC_Sprayer
**Назначение:** Управление распылителем для сельского хозяйства.

Компоненты:
- Помпа (pump) — скорость распыления пропорциональна скорости аппарата
- Спиннер (spinner) — распределение раствора

Настройка: `RC7_OPTION=15` (включение/выключение), `SERVO10_FUNCTION=22` (помпа), `SERVO11_FUNCTION=23` (спиннер).

---

### AC_WPNav
**Назначение:** Навигация по путевым точкам для мультиротёра.

Особенности:
- Плавное движение между точками с SCurve/Spline траекториями
- Ограничение ускорения и скорости
- Интеграция с `AC_PosControl` и `AC_Avoidance`

```cpp
#include <AC_WPNav/AC_WPNav.h>
wp_nav.set_desired_location(target_loc);
wp_nav.update_wpnav();
```

Параметры: `WPNAV_SPEED`, `WPNAV_SPEED_DN`, `WPNAV_ACCEL`, `WPNAV_LOIT_SPEED` и др.

## 3. Библиотеки аппаратного обеспечения (AP_HAL)

### AP_HAL
**Назначение:** Абстракция аппаратного обеспечения — ядро всей платформы.

Ключевые интерфейсы:
| Класс | Описание |
|-------|----------|
| `UARTDriver` | Последовательные порты |
| `AnalogIn` | АЦП (аналого-цифровое преобразование) |
| `Storage` | Хранилище (EEPROM/Flash) |
| `GPIO` | Управление GPIO |
| `RCInput` | Вход RC-сигналов |
| `RCOutput` | Выход PWM/DSHOT |
| `Scheduler` | Планировщик задач |
| `Semaphores` | Синхронизация |
| `Util` | Утилиты платформы |

```cpp
#include <AP_HAL/AP_HAL.h>
extern const AP_HAL::HAL& hal;
hal.serial->serial(0)->printf("Hello\n");
hal.gpio->pinMode(13, HAL_GPIO_OUTPUT);
```

---

### AP_HAL_ChibiOS
**Назначение:** Реализация HAL для микроконтроллеров STM32 (ChibiOS RTOS).

Поддерживаемые платформы: Cube, Pixhawk, и др. большинство полётных контроллеров.

---

### AP_HAL_Linux
**Назначение:** Реализация HAL для Linux-based платформ.

Поддержка: BeagleBone, Navio, Erle-Brain, и др.

---

### AP_HAL_ESP32
**Назначение:** Реализация HAL для ESP32.

Особенности:
- WiFi и BLE
- Низкая стоимость hardware
- Ограниченная функциональность по сравнению с STM32

---

### AP_HAL_SITL
**Назначение:** Программная реализация HAL для симуляции (Software-In-The-Loop).

Используется для:
- Разработки и отладки без реального hardware
- Автоматизированного тестирования
- CI/CD пайплайнов

Запуск:
```sh
./waf configure --board sitl
./waf blimp
Tools/autotest/autotest.py build.Blimp test.Blimp
```

---

### AP_HAL_Empty
**Назначение:** Заглушка HAL для новых платформ (шаблон).

---

### AP_HAL_QURT
**Назначение:** Реализация HAL для Qualcomm QURT (QuRT RTOS).

## 4. Сенсоры и навигация (AP_)

### AP_AHRS
**Назначение:** Attitude Heading Reference System — определение ориентации аппарата в пространстве.

Компоненты:
- Объединяет данные гироскопа, акселерометра, компаса, GPS, оптического потока
- Предоставляет кватернионы, углы Эйлера, скорость, позицию
- Поддерживает EKF2 и EKF3

```cpp
#include <AP_AHRS/AP_AHRS.h>
AP_AHRS &ahrs = AP::ahrs();
Vector3f euler = ahrs.get_euler();
```

---

### AP_InertialSensor
**Назначение:** Датчики инерции — гироскопы и акселерометры.

Особенности:
- Калибровка акселерометра (`AP_AccelCal`)
- Компенсация температуры
- Оценка вибраций
- Поддержка множества датчиков (IMU1, IMU2, ...)

---

### AP_Compass
**Назначение:** Магнитометры (компасы).

Бэкенды: I2C, SPI, внешние AHRS, MSP.

Особенности:
- Автокалибровка
- Компенсация моторов (`PerMotor`)
- Коррекция наклонения (declination)

Параметры: `COMPASS_OFS_X`, `COMPASS_OFS_Y`, `COMPASS_OFS_Z`, `COMPASS_AUTOCAL`.

---

### AP_GPS
**Назначение:** GPS-приёмники.

Бэкенды: uBlox, MTK, NMEA, SBF (Septentrio), GSOF (Trimble), SITL и др.

```cpp
#include <AP_GPS/AP_GPS.h>
AP_GPS &gps = AP::gps();
Location loc = gps.location();
```

---

### AP_Baro
**Назначение:** Барометрические датчики высоты.

Бэкенды: MS5611, BMP280, SPL06, DPS280, и др.

---

### AP_Airspeed
**Назначение:** Датчики воздушной скорости.

Используется в самолётах и вертолётах для управления на основе воздушной скорости.

---

### AP_RangeFinder
**Назначение:** Датчики расстояния (ультразвуковые, лазерные, ToF).

Бэкенды: MaxBotix, TeraRanger, LightWare, VL53L0X, и др.

---

### AP_Proximity
**Назначение:** Датчики ближнего действия для обнаружения препятствий.

Бэкенды: SF40C, TeraRanger, Becon, SITL и др.

---

### AP_OpticalFlow
**Назначение:** Датчики оптического потока для оценки горизонтальной скорости.

---

### AP_VisualOdom
**Назначение:** Визуальная одометрия для оценки позиции и скорости.

---

### AP_InertialNav
**Назначение:** Инерциальная навигация — оценка позиции и скорости по данным IMU.

Использует EKF или резервный фильтр.

---

### AP_NavEKF2 / AP_NavEKF3
**Назначение:** Расширенные фильтры Калмана (Extended Kalman Filter).

- **NavEKF2** — 24- state EKF, второе поколение
- **NavEKF3** — 24-state EKF, текущее поколение (используется по умолчанию)

Объединяют: IMU, GPS, барометр, компас, оптический поток, визуальную одометрию, ветровой стекломер.

---

### AP_NavEKF
**Назначение:** Общий интерфейс для навигационных фильтров.

---

### AP_DAL
**Назначение:** Data Abstraction Layer — абстракция данных сенсоров для EKF.

---

### AP_Terrain
**Назначение:** Данные о рельефе местности (цифровые карты высот).

Используется для:terrain follow, terrain avoidance, RTL.

---

### AP_Declination
**Назначение:** Магнитное склонение (World Magnetic Model).

```cpp
float intensity, declination, inclination;
AP_Declination::get_mag_field_ef(lat, lon, intensity, declination, inclination);
```

---

### AP_GyroFFT
**Назначение:** Spectral analysis гироскопических данных (FFT) для настройки notch-фильтров.

---

### AP_AccelCal
**Назначение:** Калибровка акселерометров.

---

### AP_TempCalibration
**Назначение:** Температурная калибровка датчиков.

---

### AP_TemperatureSensor
**Назначение:** Датчики температуры для мониторинга и калибровки.

---

### AP_SurfaceDistance
**Назначение:** Расстояние до поверхности земли (объединяет данные от多个 датчиков).

---

### AP_Airspeed
**Назначение:** Датчики воздушной скорости.

- Отправка телеметрии (ATTITUDE, GPS_RAW, SYS_STATUS)

- Настройка параметров

---

**Назначение:** Управление последовательными портами и протоколами.

---

### AP_RCTelemetry
**Назначение:** Телеметрия обратно через RC-канал (FrSky, CRSF, Spektrum, Crossfire и др.).

---

### AP_Frsky_Telem
**Назначение:** Протокол телеметрии FrSky (S.Port, FPort).

---

### AP_Hott_Telem
**Назначение:** Протокол телеметрии Graupner HOTT.

---

### AP_IBus_Telem

---

### AP_LTM_Telem

---

### AP_Devo_Telem

---

### AP_NMEA_Output
**Назначение:** Вывод данных в формате NMEA через последовательный порт.

---

### AP_MSP

### AP_DDS

### AP_Networking

### AP_ADSB

### AP_OpenDroneID

## 9. Симуляция (SITL)

### SITL
**Назначение:** Software-In-The-Loop — полная симуляция полёта.

Модели:
- `SIM_Aircraft` — базовый класс
- Квадрокоптеры, самолёты, вертолёты, rover, submarine
- Поддержка多种 сценариев: ветер, GPS, магнитное поле, барометр

Запуск:
```sh
# Сборка
./waf configure --board sitl
./waf blimp

# Запуск симуляции
Tools/autotest/sim_vehicle.py -v Blimp

# Автотесты
Tools/autotest/autotest.py build.Blimp test.Blimp
```

## Как использовать библиотеки в проекте

### Включение библиотеки

1. **Добавить зависимость** в `wscript`:
```python
get_env().BUILD_GROUPS['blimp'].extend([
    'AP_GPS',
    'AP_Compass',
])
```

2. **Подключить заголовок**:
```cpp
#include <AP_GPS/AP_GPS.h>
#include <AP_AHRS/AP_AHRS.h>
```

3. **Получить экземпляр** (синглтон):
```cpp
AP_GPS &gps = AP::gps();
AP_AHRS &ahrs = AP::ahrs();
```

4. **Настроить параметры** через `Parameters.cpp`:
```cpp
// @Param: MY_PARAM
// @DisplayName: My parameter
// @Description: Description of what it does
// @Range: 0 100
// @User: Standard
AP_GROUPINFO("MY_PARAM", 0, AP_MyClass, my_param, 50),
```

### Сборка для Blimp

```sh
# Конфигурация для SITL
./waf configure --board sitl

# Сборка Blimp
./waf blimp
```

### Ключевые зависимости для Blimp

Blimp использует следующие библиотеки из ArduPilot:
- **AP_HAL** — аппаратный абстрактный слой
- **AP_AHRS** — определение ориентации
- **AP_GPS** — GPS-навигация
- **AP_Baro** — барометрическая высота
- **AP_Compass** — магнитная ориентация
- **AP_InertialSensor** — гироскопы и акселерометры
- **AP_Motors** — управление моторами
- **AC_AttitudeControl** — контроллер ориентации
- **AC_PosControl** — контроллер позиции
- **AC_WPNav** — навигация по путевым точкам
- **AP_Scheduler** — планировщик задач
- **AP_Logger** — логирование
- **GCS_MAVLink** — связь с GCS
- **AP_Param** — управление параметрами
